## 현재 환경
작업 시 node와 npm을 PATH에서 찾지 못했습니다. 현재 버전은 별도 설치 없이 index.html을 열어 확인할 수 있는 웹 프로토타입입니다. TDS는 아직 적용하지 않았습니다.

## SDK 전환 순서
1. Node.js 개발 환경을 준비하고 이 앱 폴더에서 `npm install`을 실행합니다.
2. `npm run dev`로 웹 화면을 확인합니다.
3. 공식 문서에 따라 `npm install @apps-in-toss/web-framework` 후 `npx ait init`을 실행합니다. 초기화 전 기존 설정 초안을 확인합니다.
4. 콘솔에 이 앱을 등록하고 `granite.config.ts`의 appName, displayName, icon을 실제 값으로 맞춥니다. 기존 커플벨·구독메모의 식별자를 재사용하지 않습니다.
5. 현재 사용자 정의 UI를 공식 TDS WebView 가이드에 맞게 검토·전환합니다.
6. SDK 초기화로 생성된 명령을 확인하고 샌드박스에서 테스트합니다. 실기기는 공식 가이드에 따라 web.host를 PC의 LAN 주소로 설정합니다.
7. 뉴스 서버를 연결하고 로딩·오류·원문 이동·저장 동작을 실기기에서 검증합니다.
8. `ait build`로 번들을 생성해 업로드하고 토스앱 테스트 후 검토 요청을 진행합니다.

SDK 설치 전 현재 package.json의 build는 일반 웹 빌드만 수행하며 .ait 번들을 만들지 않습니다. 배포 가능 상태로 간주하지 않습니다.
