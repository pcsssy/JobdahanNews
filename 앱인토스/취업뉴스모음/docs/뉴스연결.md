# 실제 뉴스 연결

## 키 발급
1. 네이버 클라우드 콘솔의 **NAVER API HUB > Application**을 엽니다. 기존 네이버 개발자센터의 검색 API 신규 신청은 종료되었습니다.
2. Application 등록에서 **뉴스 검색** API를 선택하고 이름을 `취업뉴스모음`으로 입력합니다.
3. 생성된 Application의 **API 관리 > 인증 정보**를 엽니다.
4. NAVER API HUB의 Client ID와 Client Secret을 확인합니다.
5. 앱 폴더의 `.env.example`을 `.env`로 복사하고 두 값을 채웁니다. 키를 채팅이나 소스 파일에 붙여넣지 않습니다.
6. `시작.ps1`을 실행하고 http://127.0.0.1:5173 을 엽니다. 키 변경 후 서버를 재시작합니다.

## 구현
- Node.js 기본 모듈만 사용하는 로컬 서버. 별도의 npm 패키지 설치 없이 실행합니다.
- `/api/news?q=검색어&tag=반도체&tag=AI&page=2` → 네이버 뉴스 검색 API.
- 선택 분야마다 날짜순 20건을 요청하고 원문 URL 중복을 합쳐 최신순으로 표시합니다. `뉴스 더 보기`는 각 검색의 다음 페이지를 불러옵니다. 전체 언론 기사를 모두 제공하는 것은 아닙니다.
- 관심 뉴스 탭은 저장한 관심 분야를 사용합니다. 전체 뉴스 탭은 현재 선택을 사용합니다.
- 출처는 원문 도메인으로 표시합니다. 날짜는 공급 API의 pubDate이며 원문 발행 시각과 다를 수 있습니다.
- 서버는 인증키를 브라우저에 보내지 않으며 정적 파일 경로를 제한합니다. 상류 요청 8초, 브라우저 15초 제한과 입력 지연 검색을 적용합니다.
- 일부 분야 실패, 전체 실패, 키 미설정, 빈 검색 결과를 구분합니다. 가상 뉴스로 대체하지 않습니다.
- 브라우저에 북마크 최대 100개를 저장합니다. 서버에는 뉴스 결과를 영구 저장하지 않습니다.
- 전체 서버 기준 분당 20요청, 동시 3요청으로 로컬 오용을 제한합니다. 공개 배포용 인증·분산 호출 제한은 별도 작업입니다.

## 검증 및 남은 단계
`node --test server/news.test.mjs`는 공급자 응답을 대체한 자동 테스트입니다. 실제 API 성공 여부는 유효한 키를 넣은 뒤 확인해야 합니다.
현재 서버는 PC 내부에만 열립니다. 앱인토스 출시에는 별도 HTTPS 서버, API 주소 연결, SDK 원문 열기 동작 검증, 공급자 콘텐츠 이용 조건 검토가 남아 있습니다. 정적 웹 번들만 업로드하면 이 Node 서버가 같이 배포되는 것은 아닙니다.

현재 서버 주소: `https://naverapihub.apigw.ntruss.com/search/v1/news`
인증 헤더: `X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY`. 환경변수 이름은 기존과 동일합니다.

공식 API 문서: https://api.ncloud-docs.com/docs/naver-api-hub-search-news
키 발급 및 인증: https://api.ncloud-docs.com/docs/naver-api-hub-overview
