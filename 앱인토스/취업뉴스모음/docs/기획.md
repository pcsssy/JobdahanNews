# 기획

> 구현 현황 갱신: 네이버 검색 API 서버 어댑터와 실제 뉴스 화면을 구현했습니다. API 키 등록 및 실제 공급자 연결 검증은 대기 중입니다. 초기 범위 기록보다 [뉴스연결.md](뉴스연결.md)가 우선합니다.

## 목적
지원하는 업계에서 어떤 변화가 일어나는지 빠르게 확인한다. 채용 공고 수집과는 구분한다.

## 분류
- 산업: 반도체, 로봇, 의료·바이오, AI, 금융, 모빌리티
- 직무: 개발, 연구개발, 회계·재무, 영업, 마케팅
- 산업과 직무는 별도 태그다. 한 기사는 여러 태그를 가질 수 있다.
- 첫 버전은 선택한 분야 중 하나라도 일치하는 뉴스를 보여준다. 산업과 직무의 교집합 추천은 후속 기능이다.

## 첫 화면 흐름
뉴스 탐색 → 분야 선택 또는 검색 → 기사 확인 → 북마크.
관심 분야는 현재 필터를 저장해 반복 설정을 줄인다.

## 실제 뉴스 연동 전 결정할 항목
1. 공급자와 콘텐츠 이용 조건: 네이버 뉴스 검색 API 등을 검토하되 사용 범위와 저장·가공 조건을 확인하고 확정한다.
2. 서버: 공급자 인증키는 프런트엔드에 넣지 않는다. 서버에서 검색 요청, 호출량 제한, 오류 처리를 담당한다.
3. 기사 표시: 제공이 허용된 제목·발행 시각·출처·짧은 설명과 원문 링크를 중심으로 구성한다. 기사 전문 복제는 기본 범위에 포함하지 않는다.
4. 데이터 품질: 중복 URL 제거, 발행 시각 정규화, 관련 없는 검색 결과 제거, 산업·직무 태깅.
5. 실제 응답이 없거나 실패하면 빈 상태·재시도를 표시한다. 가상 뉴스를 실제 뉴스처럼 대신 표시하지 않는다.

## 후속 기능
- 기사별 개인 메모와 면접 질문 정리
- 기간별 업계 흐름 보기
- 로그인·기기간 동기화는 첫 버전 이후 검토

## 현재 범위
로컬 화면 프로토타입. 실시간 뉴스·AI 요약·알림·로그인·수익화·출시는 미구현.
