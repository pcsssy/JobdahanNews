# 출시용 뉴스 서버 배포

앱인토스 번들은 정적 파일이라 네이버 뉴스 API 키를 직접 넣으면 안 됩니다. 이 프로젝트의 `api/news.mjs`를 Vercel Serverless Function으로 배포하고, 그 주소를 번들에 넣습니다.

1. Vercel에서 GitHub의 `pcsssy/JobdahanNews` 저장소를 Import합니다.
2. **Root Directory**를 `앱인토스/취업뉴스모음`으로 선택합니다.
3. Environment Variables에 아래 두 값을 **Production, Preview 모두** 등록합니다.
   - `NAVER_CLIENT_ID`
   - `NAVER_CLIENT_SECRET`
4. Deploy합니다. 배포 주소가 예를 들어 `https://news4job-api.vercel.app`이면, 다음 명령으로 출시 번들을 만듭니다.

```powershell
$env:NEWS_API_BASE = 'https://news4job-api.vercel.app'
& 'C:\Users\chan seo\Documents\ChatGPT\앱인토스_고조선\.tools\node-v24.21.0-win-x64\npm.cmd' run build:release
```

5. 생성된 `news4job.ait`를 앱인토스 개발자센터에 업로드해 QR 테스트 후 출시 검토를 요청합니다.

Vercel URL의 `/api/news?q=AI`를 브라우저에서 열었을 때 JSON이 표시되면 뉴스 서버 연결이 완료된 것입니다.
