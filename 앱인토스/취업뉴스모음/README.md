# 취업뉴스모음

## 최신 상태: 실제 뉴스 API 연결 코드 준비

`시작.ps1`로 서버를 실행하고 http://127.0.0.1:5173 에서 확인합니다. `.env`에 네이버 검색 API 키를 넣고 서버를 재시작하면 실제 뉴스를 요청합니다. [발급·실행 안내](docs/뉴스연결.md)를 참고하세요.

현재 진입점은 `src/live-app.js`, 분류 목록은 `src/data/categories.js`, 서버는 `server/`입니다. 아래 초기 프로토타입 기록과 달리 index.html 직접 열기로는 실제 뉴스를 가져올 수 없습니다. 기존 `src/app.js`와 `demo-news.js`는 초기 구현 기록이며 현재 화면에서 사용하지 않습니다.

공급자 응답을 대체한 자동 테스트 7개와 로컬 HTTP 응답을 검증했습니다. 유효한 키를 통한 실제 기사 수신, 앱인토스 SDK·실기기 검증, 공개 HTTPS 서버 배포는 아직입니다.

---

## 초기 프로토타입 기록

관심 산업과 직무의 흐름을 읽고 취업 준비에 활용하는 모바일 뉴스 앱입니다.

## 현재 실행 방법

`index.html`을 브라우저에서 열면 동작합니다. 모든 기사는 기능 확인용 가상 예시이며 실제 보도가 아닙니다.

구현: 산업·직무 필터(선택한 항목 중 하나라도 일치), 검색, 관심 분야 저장, 관심 뉴스 보기, 북마크, 새로고침 후 설정 복원, 빈 결과 안내. 저장은 현재 브라우저에만 적용되며 브라우저가 저장을 차단하면 안내합니다.

## 파일 구조

```text
취업뉴스모음/
  index.html             화면 진입점
  src/
    app.js               화면과 사용자 동작
    styles.css           모바일 화면 스타일
    data/demo-news.js     가상 뉴스와 분야 목록
  docs/
    기획.md               기능 범위와 다음 단계
    개발가이드.md         공식 문서와 앱인토스 연결 절차
  package.json           웹 개발 도구 명령
  granite.config.ts      앱인토스 SDK 설정 초안
```

현재 앱인토스 SDK 설치·번들 빌드·실기기 검증·실제 뉴스 API 연결은 완료되지 않았습니다. 콘솔 등록이나 배포도 하지 않았습니다. `granite.config.ts`의 appName과 아이콘은 콘솔 등록 후 확정해야 합니다.
